ARES v1.4 HARE methodology

Observation layer: every APR access/network record is retained without claiming it is a user action.

Primary signals: sustained microphone/camera, Camera app use, and clustered browser/video traffic can establish or strongly indicate active use.

Supporting signals: Contacts, Photos, Location and ordinary network traffic support an activity but normally do not create one alone.

Segmentation: same-app primary observations separated by short gaps are merged into a single human-level activity item.

Two confidence dimensions: Evidence status is separate from User Involvement.

Network context: network records are attached to overlapping/nearby user activities where possible. Isolated network records remain background context.

Behavioural transition rule: direct Phone/Contacts activity + unusual Contacts-resource access + possible Settings/system transition + change in later call/contact behaviour → Potential Contact-Management Event. Missing components reduce confidence; no APR-only candidate is called a confirmed block/unblock.

APR limits: no universal Screen Time, message content, call direction, participant identity, or proof of individual text-message sends.
